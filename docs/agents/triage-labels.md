# Triage Labels

这些标签用于描述 issue 当前处于哪个处理状态。mattpocock/skills 会使用左侧的标准角色，并映射到右侧 GitHub Issues 里的实际标签名。

| mattpocock/skills 标准角色 | 本仓库实际标签 | 含义 |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | 需要维护者评估 |
| `needs-info` | `needs-info` | 等待提出者补充信息 |
| `ready-for-agent` | `ready-for-agent` | 需求已经清楚，AI agent 可以接手 |
| `ready-for-human` | `ready-for-human` | 需要人类实现或判断 |
| `wontfix` | `wontfix` | 不处理 |

当 skill 提到某个 triage 角色时，使用本表右侧对应的标签名。

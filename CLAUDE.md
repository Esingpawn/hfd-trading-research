## Design System

Always read `DESIGN.md` before making any visual or UI decisions.

All font choices, colors, spacing, component density, motion, and aesthetic direction are defined there. Do not deviate without explicit user approval.

In QA or review mode, flag UI code that does not match `DESIGN.md`.
